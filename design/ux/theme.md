# Theme

The visual direction is a clean coaching board: cool ice surfaces, dark navy text, Blue and Orange teams, and a warm gold focus/highlight color.

| Role            | Value     |
| --------------- | --------- |
| Page background | `#edf4f7` |
| Surface         | `#ffffff` |
| Text            | `#152638` |
| Muted text      | `#5a6c7c` |
| Border          | `#cfdae1` |
| Blue team       | `#1261a0` |
| Orange team     | `#c45100` |
| Focus/selection | `#d89500` |

Use the system sans-serif stack, large tightly spaced lesson headings, 44px minimum interactive controls, 1.1rem card corners, and restrained cool shadows. Layout changes at 820px; portrait guidance appears below 600px. Focus uses a three-pixel gold outline, and reduced-motion users receive immediate formation updates.
