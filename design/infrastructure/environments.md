# Environments

| Environment | Purpose                            | Delivery                             |
| ----------- | ---------------------------------- | ------------------------------------ |
| Local       | Development and interaction checks | `npm start` on loopback              |
| CI          | Reproducible verification          | `npm ci`, tests, production build    |
| Production  | Public lesson                      | Static HTTPS files with SPA fallback |

There is no environment-specific application configuration or data.
